# Lloyd Achankeng's Python API Automation Project

This is my first test of my capabilities for learning python, wathcing tutorials, using the internet and resources, and implmenting API and stuff into my scripts

A modular Python automation script that interacts with a REST API using GET, POST, and PATCH requests. Includes structured logging, reusable functions, and a clean main() driver. Demonstrates real backend engineering patterns used in API automation roles.

## Features

- Fetch all posts from an API
- Fetch comments for any post
- Create new posts using POST requests
- Update existing posts using PATCH requests
- Centralized logging with timestamps
- Modular reusable function-based architecture
- Professional main() driver function
